## 🧠 Description
**Multi-Agent Conversion** est un outil basé sur une architecture multi-agents permettant de convertir automatiquement du code d’un langage vers un autre, tout en maintenant sa structure et en générant un fichier de sortie prêt à l’emploi.  
L’application est équipée d’une **interface graphique (Tkinter)** pour simplifier l’utilisation.

---

## ✨ Fonctionnalités
- 🔄 Conversion entre plusieurs langages (Python, Java, C++, JavaScript, COBOL, Ruby, etc.)  
- 🖥️ Interface graphique simple et intuitive (Tkinter)  
- 💾 Génération automatique d’un fichier de sortie dans le langage cible  
- 📊 Surveillance en temps réel de l’utilisation CPU et RAM  
- 📖 Génération automatique de documentation expliquant les changements entre les codes
